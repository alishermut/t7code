# Tasks

Tasks are a **project backlog**. They outlive a session. They are not the same as the in-chat **Tasks: 3 of 7** badge, which only shows what the current turn is doing.

Open **Tasks** from the sidebar row under Search, or from the command palette (**Open tasks**). Pick a project. Use **New task** or a column **+** to add a goal. Name and explanation become the prompt when an agent claims the work. Drag a card between Open, Doing, Blocked, and Done. A claimed task links to its session; that session shows the task in the thread header.

Agents in that project get the same backlog automatically through T3’s MCP tools (`tasks_list`, `tasks_create`, `tasks_update`, `tasks_claim`). They can file work, split a goal, claim it for the current session, and mark it done. You and the agents write the same list.

The Tasks page is on web and desktop. Mobile can still drive the same environment; the backlog lives on the server.
